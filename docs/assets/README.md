# Images in this directory

| File | Where it is used | Size |
|---|---|---|
| `hero.svg` | top of the repository `README.md`, 1920×360 banner | the lockup and the approved brand background |
| `cycle.svg` | the "What it does" section of `README.md`, 1000 wide (the height follows from the content) | the delivery process as a flow chart, mirroring the process chart of "How we build with AI agents" |

Both are generated by [`build_assets.py`](build_assets.py). Edit the script, not the SVGs — a
hand edit to an SVG is lost the next time anyone regenerates it.

## Why they are generated

GitHub renders an SVG inside an `<img>`, where no web font can load, so a `<text>` element would
fall back to whatever sans the reader's machine happens to have. Every piece of type in both
files is therefore **converted to outlines** from the brand typeface (Fustat) before it is
written out: the variable font is instantiated at the weight in use, the glyph outlines are drawn
through an SVG path pen, and each run is laid out with the font's own advance widths plus its
GPOS kerning pairs.

The 10Clouds wordmark in the hero is **never redrawn**. Its paths are inlined verbatim from the
canonical brand SVG and only uniformly scaled, so that its cap height matches the Fustat word
sitting on the same baseline.

## Regenerating

```bash
python3 -m venv /tmp/svgvenv && /tmp/svgvenv/bin/pip install fonttools
/tmp/svgvenv/bin/python docs/assets/build_assets.py
```

A virtual environment is the reliable route because a system Python on macOS refuses
`pip install --user` (PEP 668).

Two inputs live outside this repository, and the script looks for them in the usual places.
Point at them explicitly when it cannot find them:

```bash
FUSTAT_TTF=~/Library/Fonts/Fustat.ttf \
BRAND_ASSETS=/path/to/10cfi-brand/assets/brand \
/tmp/svgvenv/bin/python docs/assets/build_assets.py
```

- `FUSTAT_TTF` — the Fustat variable font (weight axis 200–800).
- `BRAND_ASSETS` — the directory holding `wordmark-10clouds.svg` and `hero-lens@1x.jpg`, the
  approved wide brand composite that the hero embeds as a data URI.

If the brand directory is missing, the script stops rather than substituting a drawn wordmark.

## Checking the result

```bash
rsvg-convert -w 1200 docs/assets/hero.svg  -o /tmp/hero.png
rsvg-convert -w 560  docs/assets/cycle.svg -o /tmp/cycle.png
```

560 px is the width the diagram is embedded at in the README, so it is the width to judge it at.
Both files have their own dark background and so read the same in GitHub's light and dark themes.

## What the diagram shows

Top to bottom, the same stages as the PDF: an optional Slack thread or client message that the
agent drafts into the ticket, the ticket, the project model, Build (1 rung, 2 interview, 3 spec,
4 tests first by a separate agent, 5 write the code), Verify on the running app, Code review (an
agent reviews the diff), Cleanup, the Critic (mandatory on risky changes or near a core
capability), Commit and push (to
`main` or as a pull request), CI unit tests, Staging (ticket In Review), CI e2e tests, the human
check on production, and Done, with a bug sending the work to a new ticket while this one stays
In Review. The left band marks the stages that run under the shared board, where parallel
sessions see each other. The right rail shows the ticket status following the code.

## Conventions inside the diagram

Three line and box styles, each meaning exactly one thing, and all three are in the diagram's
own legend:

- **solid arrow** — a step that always happens,
- **dashed box outline** — this block is optional (the Slack origin, and the critic on a change that is not risky),
- **dotted arrow** — a loop back (Verify to step 5, the critic's FAIL, "not yet" to staging).
- **rounded pill** — an automated CI gate (unit tests before staging, e2e tests before production).

Never reuse one of those styles for a second meaning; that was the first thing a fresh reader
tripped over. The person icon means "you", and appears at every point where a human is required.

## Palette

Deep Blue `#081735`, Signal Blue `#152E61`, Deep Teal `#29555E`, Mist Green `#D3E3D8`, White —
the 10Clouds brandbook palette, no other values. Type is Fustat in Regular, Medium and, for the
product word in the hero, Light.
